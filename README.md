# ai-learning-coach-pro
# 🧭 AI 学习陪跑顾问

一个懂你的 AI 学习陪跑系统。它会记住你的学习情况，陪着你一步步学 AI。

## ✨ 功能

- **首次问卷**：第一次使用时，填一份问卷，AI 会记住你的身份、目标、学习偏好。
- **长期记忆**：每次对话后，AI 自动提炼一条值得记住的信息，越用越懂你。
- **知识库问答**：支持上传 PDF / TXT / PPTX / DOCX 学习资料，AI 结合资料回答。
- **两种使用方式**：
  - 🎁 体验模式：10 次免费体验
  - 🔑 自定义 API：绑定你自己的智谱 API Key，长期使用
- **参考来源**：回答中标注引用了哪几块资料
- **历史记录**：对话和文件记录保存在本地数据库

## 🛠 技术栈

- **前端**：Streamlit
- **RAG 框架**：LangChain
- **向量数据库**：Chroma
- **嵌入模型**：智谱 embedding-2
- **对话模型**：智谱 glm-3-turbo
- **数据库**：SQLite
